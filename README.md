# Liberty or Death — mode solo

Maquette web du jeu de plateau *Liberty or Death* (GMT Games) avec les factions non-joueurs jouées par le programme
(règles section 8). Jouable directement dans le navigateur, sans serveur.

- **Jouer** : `web/solo/plateau.html` (plateau interactif, pièces glissables, actions des ordinateurs animées)
- **Vue détaillée** : `web/solo/solo.html` (tableau de saisie + journal)
- Documentation du moteur et hypothèses : `web/solo/README_solo.md`

Mise en ligne : GitHub Pages (branche `main`, dossier racine). L'URL de jeu est alors
`https://<ton-compte>.github.io/<nom-du-depot>/` (redirige vers le plateau).
